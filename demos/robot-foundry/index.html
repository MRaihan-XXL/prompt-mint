Five skulls, four faces, endless parts.

Seeded silhouettes, optics, jaws, fins, pods and cables. Each plate gets a bevel, shade, panel gap and edge light — the same seed always forges the same head.

02 / SVG export

Standalone, with every halo.

Gradients, clip paths, glow layers and all nine groups are serialized into a single 480×480 file. Open it in any editor — nothing is rasterized.
